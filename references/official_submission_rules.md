# SAIF 2026 — Official Submission Rules Reference

Use this file only for competition requirements that are explicitly stated in the provided SAIF platform guide, official poster template, poster-preparation guide, and the project's official track list.

## Source precedence
1. Official SAIF platform guide and official poster template.
2. Official poster-preparation guide.
3. Officially provided competition track list.
4. Judge/expert training video for interpretation and presentation guidance, not as an official scoring rubric.
5. Internal diagnostic models created by these skills are advisory only and must never be presented as official SAIF judging criteria.

## Project submission language
- Project information and submitted documents must be in English.
- The introductory video may be in Arabic or English.

## Team
- Participation may be individual or as a team.
- Maximum team size: 6 members including the team leader.
- All team members must belong to the same age category.
- Age categories:
  - 6–11 years
  - 12–17 years
  - 18 years and above
- Only the team leader can edit and submit the project.

## Project information
- Final project / innovation name must be used.
- Marketing summary maximum: 500 characters.
- Select the project category / track and presentation format from the platform lists.
- Required fields are marked with *.
- Do not place email addresses or personal data in the project-name field.

## Intellectual property and prior participation
- Select the IP status accurately, such as none, registered, or pending registration.
- State accurately whether the project has been presented in a previous competition or exhibition.
- If yes, complete the additional participation / awards details.

## Required and optional files
### Scientific Poster
- Mandatory.
- PDF only.
- Maximum file size: 50 MB.
- Must use the approved SAIF poster template without changing its structure / identity.

### Project Image
- Optional in the upload section, but recommended for a complete presentation package.
- Maximum file size: 50 MB.
- Accepted formats: PDF, PNG, JPEG.

### Introductory Video
- Optional.
- Maximum duration: 5 minutes.
- Maximum file size: 150 MB.
- Arabic or English.

## Google Drive
- The additional-links field is mandatory and accepts a Google Drive folder link.
- Supporting files and evidence may be placed in that folder.
- Sharing must be: Anyone with the link.
- Permission must be: Viewer.
- Verify the link in a logged-out / alternate browser before submission.

## Saving and final submission
- Save Draft does not submit the project.
- Submission is completed by pressing Save Changes after all required fields are complete.
- Verify that the dashboard log shows that the team leader submitted the project.
- The project can be edited and resubmitted before the deadline; the latest saved version is used.
- After submission closes, editing/submission is locked.
- After submission, open View Project and check what the judges will see.

## Scientific poster technical requirements
- Official size: 48 × 36 inches (121.9 × 91.4 cm), portrait orientation.
- Do not change the page dimensions.
- Export as PDF only, not PNG/JPEG.
- Use IBM Plex Sans Arabic or another clear readable font; the poster content itself is in English.
- Keep roughly 10–15% of the poster area blank to reduce visual clutter.
- Keep the fixed template element order.
- Poster title and all team member names must be in English.
- After qualification, add assigned team ID and booth number when provided.
- QR code area may link to references, attachments, and supporting files.
- Acknowledgments statement should identify funding sources, host laboratories, or supporting institutions if applicable.

## Poster sections
The official template uses:
1. Introduction
2. Methodology
3. Results
4. Innovation
5. Conclusion
6. Future Work & References

## Non-negotiable source rule
Never invent a SAIF rule, weight, judging criterion, file requirement, deadline, IP condition, prototype requirement, or team rule. If a requested condition is not in the source pack, answer: "Not specified in the provided SAIF materials." Internal readiness scores must be labeled as advisory diagnostics, never as official judging scores.
