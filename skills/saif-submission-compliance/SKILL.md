# SAIF Submission Compliance

## Goal
Prevent administrative or technical submission failure.

## Authoritative source
Use `../references/official_submission_rules.md`.
Do not add rules from memory or from other competitions.

## Hard-gate checklist
Mark each item PASS / FAIL / UNKNOWN / N/A.

### Account and team
- Team leader is using the invited account.
- Team size <= 6 including leader.
- All members are in the same age category.
- All intended members were added before final submission.

### Project information
- Final project name entered.
- All required fields complete.
- Marketing summary <= 500 characters.
- Correct project track/category selected.
- Presentation format selected if required by the portal.
- No personal contact data in project-name field.

### IP and prior participation
- IP status is accurate.
- Prior exhibition/competition participation is answered accurately.
- Additional prior-participation details are completed if applicable.

### Poster
- Mandatory poster exists.
- Uses official template.
- Structure/identity not changed.
- Content is in English.
- PDF format.
- <= 50 MB.
- Correct age-category background.

### Project image
- Optional.
- If provided: PDF/PNG/JPEG and <= 50 MB.

### Video
- Optional.
- If provided: <= 5 minutes, <= 150 MB.
- Arabic or English.

### Google Drive
- Required link provided.
- Folder is set to Anyone with the link.
- Permission is Viewer.
- Link opens without sign-in.

### Final submission
- Required-field counter reaches zero / all required fields complete.
- User presses Save Changes, not only Save Draft.
- Dashboard confirms that the team leader submitted the project.
- View Project is opened and final visible content is checked.

## Completion percentage
Use the `Submission Completeness` model from `project_readiness_model.md`.
This is an internal completion percentage, not a judging score.

## Failure policy
Any FAIL on a mandatory item means:
`Status: NOT SUBMISSION-READY.`

Then provide the shortest possible fix list in priority order.

## If the user asks one narrow question
Answer only that requirement and its exact limit. Do not dump the full checklist unless requested.
